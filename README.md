
# IT Helpdesk & Network Troubleshooting Lab

**Rakesh Lakshmanan**  
IT Support | Networking | Cybersecurity

## About This Project

This portfolio demonstrates practical IT support and troubleshooting skills through hands-on exercises and simulated helpdesk scenarios.

The project focuses on Windows troubleshooting, network diagnostics, application support, ticket documentation, and network traffic analysis.

## Objectives

- Troubleshoot common Windows issues.
- Diagnose network connectivity and DNS problems.
- Use command-line tools for technical investigation.
- Analyse network traffic using Wireshark.
- Document helpdesk incidents and resolutions.
- Understand user account support and escalation procedures.

## Tools and Technologies

- Microsoft Windows
- Command Prompt and PowerShell
- TCP/IP, DNS and DHCP
- Wireshark
- Linux command-line tools
- GitHub and Markdown

## Practical Modules

1. Windows Troubleshooting
2. Network Troubleshooting
3. Helpdesk Ticket Management
4. Wireshark Network Analysis
5. Linux Troubleshooting
6. Active Directory Fundamentals

## Troubleshooting Method

Identify the issue → Gather evidence → Investigate → Resolve → Verify → Document.
